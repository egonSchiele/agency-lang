**The stdlib entry nodes run their worker under `docsOnlyHandler`.** Each `evalMain` in `stdlib/agents/` (coding, agency review, TypeScript review, writing review) wraps its worker in `handle { ... } with docsOnlyHandler` (`std::agents/lib/shared`). That handler approves `std::read` of files under `bundledDocsDir()` (`std::skills`), the docs that ship in the package, and rejects every other interrupt. Before it, the nodes used `with reject`, which also rejected the docs-tool reads: the coding agent asked for `handlers.md`, got "interrupt rejected", and invented a handler syntax from memory.
