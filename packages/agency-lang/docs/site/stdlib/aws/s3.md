# s3

Read and write text or binary objects in Amazon S3, create buckets, and
  generate presigned download links. No AWS SDK installation is needed.

  Credentials come from the standard AWS environment variables
  (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, and optionally
  `AWS_SESSION_TOKEN`). The region defaults to `AWS_REGION`, then `us-east-1`,
  and can be overridden per call.

  ```ts
  import { s3Put, s3Get } from "std::aws/s3"

  node main() {
    s3Put("my-bucket", "notes.txt", "hello") with approve
    const text = s3Get("my-bucket", "notes.txt") with approve
    print(text)
  }
  ```

  Bind `bucket` with `.partial(bucket: "my-bucket")` before handing a
  function to an agent to keep that tool within one bucket.

  Binary uploads and downloads use base64 strings.

### s3PresignGet

```ts
s3PresignGet(
  bucket: string,
  key: string,
  expiresIn: number = 1h,
  region: string = "",
): Result<string>
```

Create a shareable download URL for a private S3 object.

The URL is computed locally without downloading the object. Treat it
  as a credential: anyone holding it can download the object. With temporary
  AWS credentials, it stops working when the session expires even if the
  requested expiry is later.

**Parameters:**

| Name | Type | Default | Description |
|---|---|---|---|
| bucket | `string` |  |  |
| key | `string` |  | A non-empty object key with no complete "." or ".." path segments. |
| expiresIn | `number` | 1h | A whole number of milliseconds from 1 through 604800000, at most seven days. |
| region | `string` | "" | Leave empty to use AWS_REGION, then us-east-1. |

**Returns:** `Result<string>`

**Throws:** `std::aws::s3::presignGet`

([source](https://github.com/egonSchiele/agency-lang/tree/main/packages/agency-lang/stdlib/aws/s3.agency#L184))
